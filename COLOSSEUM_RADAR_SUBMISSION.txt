PROBLEM STATEMENT
1. Agent counterparty risk: no trustless way for agents (or humans) to pay for
   delegated compute before verified delivery.
2. Privacy leaks: proving off-chain work on-chain exposes proprietary models,
   prompts, and data.
3. Monetization fragmentation: no standard protocol-level royalties for agent
   skill/tool developers across swarms.

SOLUTION & ARCHITECTURE
- Anchor task escrows: bounty SOL/SPL locked in escrow PDAs, released only on
  verified completion (program agenc-coordination, 42 instructions).
- RISC Zero Groth16 zkVM proofs (complete_task_private.rs): prove execution
  correctness off-chain without revealing private inputs.
- 80/20 skill marketplace: 80% of tool licensing to creators, 20% to protocol.
- 2.5% protocol fee capture on every settled escrow into the treasury PDA.
- Stack: TypeScript SDK (sdk/) + autonomous runtime (runtime/, LLM adapters,
  tool execution, delegation graphs, MCP) + MCP server (mcp/) + React+Vite
  dashboard (web/, port 5173). Daemon lifecycle via agenc-runtime CLI
  (start/status/stop/doctor -> runtime/src/cli/daemon.ts + src/gateway/daemon.ts).
